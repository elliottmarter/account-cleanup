Import accounts

Only names, website addresses, usernames, folders and dates are kept. Passwords, 2FA codes, notes and custom fields in the file are ignored and never saved. Re-importing a newer export is safe: existing accounts keep their status and new ones are added.

Getting an export from Bitwarden

  1. Open the Bitwarden web vault or desktop app → Tools (or File) → Export vault.
  2. Choose .json or .csv — not the encrypted option.
  3. Upload it here, then delete the export file from your computer (and empty the recycle bin) — Bitwarden's export contains your passwords in plain text.

Other password managers work too: any CSV with columns like name, url and username (Chrome, Firefox, 1Password, LastPass, KeePass exports).
